# Exception and recovery path

## Use when

Use this variant when validation, system, permission, or business failures materially affect experience.

## Task guidance

For **Design User Flow**, show trigger, message, retained state, recovery action, escalation, and terminal condition.

## Decision checks

- Confirm user goal, state coverage, accessibility impact, and validation evidence.
- Resolve conflicts across flow, content, layout, and platform conventions.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
