# WCAG review

## Use when

Use this variant when conformance to an accessibility standard is required.

## Task guidance

For **Review Accessibility and Usability**, evaluate perceivable, operable, understandable, and robust outcomes with criterion references and evidence.

## Decision checks

- Confirm user goal, state coverage, accessibility impact, and validation evidence.
- Resolve conflicts across flow, content, layout, and platform conventions.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
