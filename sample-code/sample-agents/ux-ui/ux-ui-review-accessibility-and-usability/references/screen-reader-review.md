# Screen reader review

## Use when

Use this variant when semantic structure and announcements are material.

## Task guidance

For **Review Accessibility and Usability**, evaluate names, roles, values, landmarks, headings, live regions, errors, dynamic updates, and reading order.

## Decision checks

- Confirm user goal, state coverage, accessibility impact, and validation evidence.
- Resolve conflicts across flow, content, layout, and platform conventions.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
