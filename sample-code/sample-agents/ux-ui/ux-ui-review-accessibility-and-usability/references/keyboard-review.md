# Keyboard interaction review

## Use when

Use this variant when users must complete the flow without a pointing device.

## Task guidance

For **Review Accessibility and Usability**, evaluate focus order, visibility, traps, shortcuts, dialogs, menus, error movement, and escape behavior.

## Decision checks

- Confirm user goal, state coverage, accessibility impact, and validation evidence.
- Resolve conflicts across flow, content, layout, and platform conventions.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
