# Complex UI state

## Use when

Use this variant when loading, empty, partial, stale, error, or permission states are material.

## Task guidance

For **Create UI Specification**, define state triggers, visual treatment, retained actions, recovery, messaging, telemetry, and transition rules.

## Decision checks

- Confirm user goal, state coverage, accessibility impact, and validation evidence.
- Resolve conflicts across flow, content, layout, and platform conventions.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
