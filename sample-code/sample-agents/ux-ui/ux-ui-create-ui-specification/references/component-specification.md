# Component specification

## Use when

Use this variant when a reusable UI component or composition is the main deliverable.

## Task guidance

For **Create UI Specification**, define anatomy, properties, variants, states, events, content limits, accessibility semantics, and examples.

## Decision checks

- Confirm user goal, state coverage, accessibility impact, and validation evidence.
- Resolve conflicts across flow, content, layout, and platform conventions.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
