# Enterprise workflow context

## Use when

Use this variant when role-based, data-dense, or operational workflows dominate.

## Task guidance

For **Analyze User and Product Context**, consider permissions, bulk operations, auditability, efficiency, error recovery, terminology, and training cost.

## Decision checks

- Confirm user goal, state coverage, accessibility impact, and validation evidence.
- Resolve conflicts across flow, content, layout, and platform conventions.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
