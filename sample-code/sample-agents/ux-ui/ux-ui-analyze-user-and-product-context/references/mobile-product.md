# Mobile product context

## Use when

Use this variant when users operate through mobile web or native interaction patterns.

## Task guidance

For **Analyze User and Product Context**, consider touch targets, constrained viewport, interruption, connectivity, permissions, orientation, and platform conventions.

## Decision checks

- Confirm user goal, state coverage, accessibility impact, and validation evidence.
- Resolve conflicts across flow, content, layout, and platform conventions.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
