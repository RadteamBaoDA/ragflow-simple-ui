# Web product context

## Use when

Use this variant when users operate primarily through a browser.

## Task guidance

For **Analyze User and Product Context**, consider viewport range, browser behavior, keyboard use, navigation, network variability, and session continuity.

## Decision checks

- Confirm user goal, state coverage, accessibility impact, and validation evidence.
- Resolve conflicts across flow, content, layout, and platform conventions.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
