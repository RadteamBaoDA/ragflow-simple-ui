# Mobile wireframe

## Use when

Use this variant when small-screen touch interaction is primary.

## Task guidance

For **Create Wireframe**, define safe areas, touch targets, navigation pattern, keyboard behavior, interruption recovery, and constrained content priority.

## Decision checks

- Confirm user goal, state coverage, accessibility impact, and validation evidence.
- Resolve conflicts across flow, content, layout, and platform conventions.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
