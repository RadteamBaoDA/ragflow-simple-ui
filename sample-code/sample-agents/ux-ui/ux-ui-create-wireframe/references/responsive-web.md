# Responsive web wireframe

## Use when

Use this variant when one web experience must adapt across viewport classes.

## Task guidance

For **Create Wireframe**, define breakpoints by content behavior, reflow, priority, navigation changes, touch considerations, and overflow.

## Decision checks

- Confirm user goal, state coverage, accessibility impact, and validation evidence.
- Resolve conflicts across flow, content, layout, and platform conventions.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
