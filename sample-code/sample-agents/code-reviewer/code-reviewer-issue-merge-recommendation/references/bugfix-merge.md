# Bugfix merge

## Use when

Use this variant when a normal-priority defect correction is entering its target branch.

## Task guidance

For **Issue Merge Recommendation**, require reproduction, root cause, regression test, affected-version analysis, review closure, and release note impact.

## Decision checks

- Confirm every finding has location, evidence, impact, severity, and required action.
- Review the change as supplied; do not silently remediate it.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
