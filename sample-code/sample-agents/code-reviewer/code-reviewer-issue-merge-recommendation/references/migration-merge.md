# Migration merge

## Use when

Use this variant when schema, data, API, or compatibility transition is included.

## Task guidance

For **Issue Merge Recommendation**, require forward and backward compatibility, ordering, validation, rollback limits, operational coordination, and staged evidence.

## Decision checks

- Confirm every finding has location, evidence, impact, severity, and required action.
- Review the change as supplied; do not silently remediate it.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
