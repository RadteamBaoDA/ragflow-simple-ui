# Feature merge

## Use when

Use this variant when a planned capability is entering its target branch.

## Task guidance

For **Issue Merge Recommendation**, require requirement traceability, review closure, tests, compatibility, rollout notes, and required role approvals.

## Decision checks

- Confirm every finding has location, evidence, impact, severity, and required action.
- Review the change as supplied; do not silently remediate it.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
