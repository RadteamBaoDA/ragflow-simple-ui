# Hotfix merge

## Use when

Use this variant when an urgent production correction uses expedited governance.

## Task guidance

For **Issue Merge Recommendation**, require incident link, minimal scope, delegated approval, focused proof, rollout and rollback, monitoring, and retrospective follow-up.

## Decision checks

- Confirm every finding has location, evidence, impact, severity, and required action.
- Review the change as supplied; do not silently remediate it.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
