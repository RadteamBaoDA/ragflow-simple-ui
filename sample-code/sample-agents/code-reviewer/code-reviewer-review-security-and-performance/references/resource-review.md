# Resource-focused review

## Use when

Use this variant when connections, memory, file handles, workers, or external quotas are involved.

## Task guidance

For **Review Security and Performance**, check acquisition, bounds, pooling, cleanup, backpressure, quota handling, telemetry, and failure recovery.

## Decision checks

- Confirm every finding has location, evidence, impact, severity, and required action.
- Review the change as supplied; do not silently remediate it.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
