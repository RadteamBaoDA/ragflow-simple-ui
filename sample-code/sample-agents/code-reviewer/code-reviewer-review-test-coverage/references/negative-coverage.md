# Negative and abuse-case coverage

## Use when

Use this variant when invalid, unauthorized, conflicting, or failure inputs are high risk.

## Task guidance

For **Review Test Coverage**, cover validation, permissions, boundary conditions, partial failure, duplicate requests, and sensitive error handling.

## Decision checks

- Confirm every finding has location, evidence, impact, severity, and required action.
- Review the change as supplied; do not silently remediate it.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
