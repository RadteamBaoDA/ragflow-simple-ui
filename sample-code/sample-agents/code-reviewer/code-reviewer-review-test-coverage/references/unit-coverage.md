# Unit test coverage

## Use when

Use this variant when local behavior and branch protection are the focus.

## Task guidance

For **Review Test Coverage**, map requirements and changed branches to assertions; evaluate negative paths, boundary values, and test independence.

## Decision checks

- Confirm every finding has location, evidence, impact, severity, and required action.
- Review the change as supplied; do not silently remediate it.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
