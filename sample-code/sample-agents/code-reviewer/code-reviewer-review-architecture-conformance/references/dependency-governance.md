# Dependency governance

## Use when

Use this variant when new or changed dependencies affect architecture.

## Task guidance

For **Review Architecture Conformance**, verify necessity, license, version support, security, runtime footprint, ownership, isolation, and replacement path.

## Decision checks

- Confirm every finding has location, evidence, impact, severity, and required action.
- Review the change as supplied; do not silently remediate it.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
