# API contract conformance

## Use when

Use this variant when request, response, event, or error shapes may have drifted.

## Task guidance

For **Review Architecture Conformance**, compare exact schemas, defaults, validation, versioning, compatibility, authorization, and consumer impact.

## Decision checks

- Confirm every finding has location, evidence, impact, severity, and required action.
- Review the change as supplied; do not silently remediate it.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
