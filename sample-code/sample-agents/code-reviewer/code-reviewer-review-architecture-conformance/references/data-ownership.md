# Data ownership conformance

## Use when

Use this variant when components may bypass the approved owner or scope.

## Task guidance

For **Review Architecture Conformance**, verify write authority, tenant and principal scope, transaction boundary, lineage, retention, and access paths.

## Decision checks

- Confirm every finding has location, evidence, impact, severity, and required action.
- Review the change as supplied; do not silently remediate it.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
