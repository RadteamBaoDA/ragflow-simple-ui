# Performance requirements

## Use when

Use this variant when response time, throughput, concurrency, or resource efficiency is material.

## Task guidance

For **Define Non-functional Requirements**, define workload, percentile or throughput target, measurement point, test duration, environment, and tolerance.

## Decision checks

- Confirm drivers, alternatives, trade-offs, failure modes, and measurable constraints.
- Identify which decisions need an ADR or accountable approval.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
