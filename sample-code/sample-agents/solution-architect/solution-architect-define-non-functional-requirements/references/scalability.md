# Scalability requirements

## Use when

Use this variant when load or data volume is expected to grow materially.

## Task guidance

For **Define Non-functional Requirements**, define baseline and target scale, growth horizon, bottlenecks, scaling trigger, and capacity evidence.

## Decision checks

- Confirm drivers, alternatives, trade-offs, failure modes, and measurable constraints.
- Identify which decisions need an ADR or accountable approval.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
