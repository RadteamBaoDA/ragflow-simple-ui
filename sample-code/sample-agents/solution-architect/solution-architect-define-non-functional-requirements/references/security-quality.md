# Security quality requirements

## Use when

Use this variant when confidentiality, integrity, authentication, authorization, or auditability is material.

## Task guidance

For **Define Non-functional Requirements**, define data classification, trust boundary, required control outcome, evidence method, and accountable security owner.

## Decision checks

- Confirm drivers, alternatives, trade-offs, failure modes, and measurable constraints.
- Identify which decisions need an ADR or accountable approval.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
