# Availability and resilience requirements

## Use when

Use this variant when continuity, recovery, or failure tolerance is material.

## Task guidance

For **Define Non-functional Requirements**, define service hours, SLO, RTO, RPO, redundancy, degraded behavior, and measurement window.

## Decision checks

- Confirm drivers, alternatives, trade-offs, failure modes, and measurable constraints.
- Identify which decisions need an ADR or accountable approval.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
