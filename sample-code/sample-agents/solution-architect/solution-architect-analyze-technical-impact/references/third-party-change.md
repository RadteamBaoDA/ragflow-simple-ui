# External dependency impact

## Use when

Use this variant when the change alters a vendor, external API, SDK, or managed service.

## Task guidance

For **Analyze Technical Impact**, map contract versions, quotas, SLA, failure modes, sandbox evidence, rollout coordination, and contingency.

## Decision checks

- Confirm drivers, alternatives, trade-offs, failure modes, and measurable constraints.
- Identify which decisions need an ADR or accountable approval.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
