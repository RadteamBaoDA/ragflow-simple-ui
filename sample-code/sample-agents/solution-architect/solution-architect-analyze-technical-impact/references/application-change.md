# Application-layer impact

## Use when

Use this variant when the change alters components, APIs, runtime behavior, or dependencies.

## Task guidance

For **Analyze Technical Impact**, map callers, callees, contracts, compatibility, feature rollout, and regression surface.

## Decision checks

- Confirm drivers, alternatives, trade-offs, failure modes, and measurable constraints.
- Identify which decisions need an ADR or accountable approval.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
