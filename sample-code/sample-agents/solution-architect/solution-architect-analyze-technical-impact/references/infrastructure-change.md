# Infrastructure impact

## Use when

Use this variant when the change alters deployment, compute, network, storage, or operations.

## Task guidance

For **Analyze Technical Impact**, map environments, capacity, security boundaries, observability, deployment order, rollback, and cost.

## Decision checks

- Confirm drivers, alternatives, trade-offs, failure modes, and measurable constraints.
- Identify which decisions need an ADR or accountable approval.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
