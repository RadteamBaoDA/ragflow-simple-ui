# Data impact

## Use when

Use this variant when the change alters schema, ownership, transformation, retention, or migration.

## Task guidance

For **Analyze Technical Impact**, map data lineage, migration, backfill, validation, rollback limits, privacy, and compatibility.

## Decision checks

- Confirm drivers, alternatives, trade-offs, failure modes, and measurable constraints.
- Identify which decisions need an ADR or accountable approval.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
