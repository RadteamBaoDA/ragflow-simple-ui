# Microservices

## Use when

Use this variant when independent deployment and bounded service ownership are justified.

## Task guidance

For **Design Solution Architecture**, define service boundaries, data ownership, synchronous and asynchronous contracts, failure isolation, operations cost, and migration path.

## Decision checks

- Confirm drivers, alternatives, trade-offs, failure modes, and measurable constraints.
- Identify which decisions need an ADR or accountable approval.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
