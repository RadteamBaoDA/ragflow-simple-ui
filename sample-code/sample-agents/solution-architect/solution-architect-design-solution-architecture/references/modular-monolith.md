# Modular monolith

## Use when

Use this variant when one deployable unit with enforced internal boundaries is appropriate.

## Task guidance

For **Design Solution Architecture**, define modules, ownership, dependency direction, transaction boundaries, internal contracts, and extraction triggers.

## Decision checks

- Confirm drivers, alternatives, trade-offs, failure modes, and measurable constraints.
- Identify which decisions need an ADR or accountable approval.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
