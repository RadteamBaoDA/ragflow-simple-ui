# Serverless architecture

## Use when

Use this variant when managed event execution and elastic consumption fit the workload.

## Task guidance

For **Design Solution Architecture**, define triggers, execution limits, state boundaries, cold-start tolerance, concurrency, cost controls, and provider portability.

## Decision checks

- Confirm drivers, alternatives, trade-offs, failure modes, and measurable constraints.
- Identify which decisions need an ADR or accountable approval.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
