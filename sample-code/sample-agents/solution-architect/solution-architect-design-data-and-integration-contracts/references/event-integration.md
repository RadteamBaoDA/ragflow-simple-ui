# Event integration contract

## Use when

Use this variant when systems integrate through messages or events.

## Task guidance

For **Design Data and Integration Contracts**, define producer, consumers, schema, compatibility, ordering, delivery guarantee, retries, dead letters, and replay.

## Decision checks

- Confirm drivers, alternatives, trade-offs, failure modes, and measurable constraints.
- Identify which decisions need an ADR or accountable approval.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
