# Third-party integration

## Use when

Use this variant when an external vendor or customer system owns part of the contract.

## Task guidance

For **Design Data and Integration Contracts**, define authoritative documentation, credentials boundary, limits, SLA, failure behavior, sandbox, change notice, and exit strategy.

## Decision checks

- Confirm drivers, alternatives, trade-offs, failure modes, and measurable constraints.
- Identify which decisions need an ADR or accountable approval.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
