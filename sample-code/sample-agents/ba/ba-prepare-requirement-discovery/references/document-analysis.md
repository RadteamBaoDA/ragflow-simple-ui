# Document analysis

## Use when

Use this variant when existing contracts, policies, reports, or legacy specifications are primary evidence.

## Task guidance

For **Prepare Requirement Discovery**, emphasize record document version and authority, extract requirements, flag conflicts, and verify stale assumptions.

## Decision checks

- Confirm the source, stakeholder, business rule, and unresolved conflict for each conclusion.
- Keep current state, desired state, proposal, and approved baseline distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
