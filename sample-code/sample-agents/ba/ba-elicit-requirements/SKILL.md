# Elicit Requirements

## Purpose

Produce an evidence-based requirement discovery record.

## Task responsibility

Own business analysis, requirement quality, and traceability. Do not make unapproved scope, architecture, implementation, test-pass, or commercial decisions.

## Reference routing

Classify the subtype before detailed work. Read only the matching reference; combine references only when the request spans multiple observable subtypes.

- Read [Stakeholder interview](references/stakeholder-interview.md) when one or a few subject-matter experts hold needed knowledge.
- Read [Facilitated workshop](references/facilitated-workshop.md) when multiple stakeholders must align on process or scope.
- Read [Document analysis](references/document-analysis.md) when existing contracts, policies, reports, or legacy specifications are primary evidence.

## Core method

1. Resolve **Source Record** using task evidence, applicable constraints, alternatives, and explicit acceptance criteria.
2. Resolve **Business Needs** using task evidence, applicable constraints, alternatives, and explicit acceptance criteria.
3. Resolve **Functional Needs** using task evidence, applicable constraints, alternatives, and explicit acceptance criteria.
4. Resolve **Non-functional Needs** using task evidence, applicable constraints, alternatives, and explicit acceptance criteria.
5. Specify **Business Rules** as measurable, traceable, unambiguous statements with accountable ownership.
6. Resolve **Open Questions** using task evidence, applicable constraints, alternatives, and explicit acceptance criteria.
7. Reconcile contradictions and state unresolved evidence, decision, and ownership gaps.

## Quality checks

- Tie each conclusion to a named stakeholder, source artifact, business rule, or labeled assumption.
- Keep business need, proposed scope, approved baseline, and technical design distinct.
- Confirm proposed changes are separated from approved baseline content.
- Confirm acceptance, approval, test, release, and customer decisions are claimed only with evidence.
