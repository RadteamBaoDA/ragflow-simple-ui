# Use case

## Use when

Use this variant when actor-system interaction is best expressed as a structured scenario.

## Task guidance

For **Write Requirement Specification**, emphasize define actor, goal, preconditions, trigger, main flow, alternate flows, postconditions, and linked rules.

## Decision checks

- Confirm the source, stakeholder, business rule, and unresolved conflict for each conclusion.
- Keep current state, desired state, proposal, and approved baseline distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
