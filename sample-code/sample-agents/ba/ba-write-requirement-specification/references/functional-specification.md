# Functional specification

## Use when

Use this variant when a bounded feature or workflow needs detailed behavior.

## Task guidance

For **Write Requirement Specification**, emphasize describe actors, triggers, preconditions, normal flow, alternatives, exceptions, business rules, and outputs.

## Decision checks

- Confirm the source, stakeholder, business rule, and unresolved conflict for each conclusion.
- Keep current state, desired state, proposal, and approved baseline distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
