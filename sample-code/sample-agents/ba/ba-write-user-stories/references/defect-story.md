# Defect story

## Use when

Use this variant when observed behavior differs from an approved expectation.

## Task guidance

For **Write User Stories**, emphasize record expected versus actual behavior, reproduction evidence, impact, affected versions, and fix acceptance.

## Decision checks

- Confirm the source, stakeholder, business rule, and unresolved conflict for each conclusion.
- Keep current state, desired state, proposal, and approved baseline distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
