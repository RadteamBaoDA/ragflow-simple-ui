# Scenario-based criteria

## Use when

Use this variant when behavior has meaningful workflows or branches.

## Task guidance

For **Define Acceptance Criteria**, emphasize use Given/When/Then scenarios covering happy path, alternatives, boundary conditions, and observable outcomes.

## Decision checks

- Confirm the source, stakeholder, business rule, and unresolved conflict for each conclusion.
- Keep current state, desired state, proposal, and approved baseline distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
