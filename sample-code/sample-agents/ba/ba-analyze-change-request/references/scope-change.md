# Scope change

## Use when

Use this variant when the request adds, removes, or materially changes an approved deliverable.

## Task guidance

For **Analyze Change Request**, emphasize compare baseline and proposal, identify impacted stakeholders and outcomes, and leave estimates to accountable roles.

## Decision checks

- Confirm the source, stakeholder, business rule, and unresolved conflict for each conclusion.
- Keep current state, desired state, proposal, and approved baseline distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
