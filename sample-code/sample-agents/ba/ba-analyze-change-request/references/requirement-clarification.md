# Requirement clarification

## Use when

Use this variant when ambiguity may be resolved without changing approved intent.

## Task guidance

For **Analyze Change Request**, emphasize quote ambiguous text, document interpretations, confirm authoritative meaning, and decide whether re-baselining is required.

## Decision checks

- Confirm the source, stakeholder, business rule, and unresolved conflict for each conclusion.
- Keep current state, desired state, proposal, and approved baseline distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
