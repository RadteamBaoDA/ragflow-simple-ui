# Workflow test cases

## Use when

Use this variant when behavior spans multiple steps or actors.

## Task guidance

For **Design Test Cases**, cover state transitions, handoffs, retries, re-entry, cancellation, permissions, notifications, audit, and terminal outcomes.

## Decision checks

- Confirm build, environment, data, preconditions, expected result, and observed result.
- Keep passed, failed, blocked, skipped, and not-tested outcomes distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
