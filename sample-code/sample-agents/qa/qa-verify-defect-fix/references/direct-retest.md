# Direct fix retest

## Use when

Use this variant when the original reproduction can be executed against the fix.

## Task guidance

For **Verify Defect Fix**, repeat exact conditions, compare expected and actual behavior, preserve evidence, and close only on observable success.

## Decision checks

- Confirm build, environment, data, preconditions, expected result, and observed result.
- Keep passed, failed, blocked, skipped, and not-tested outcomes distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
