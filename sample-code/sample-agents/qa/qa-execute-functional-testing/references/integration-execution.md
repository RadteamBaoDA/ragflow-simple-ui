# Integration functional execution

## Use when

Use this variant when end-to-end cross-system behavior is tested.

## Task guidance

For **Execute Functional Testing**, record participating versions, data, triggers, handoffs, retries, external evidence, failure behavior, and cleanup.

## Decision checks

- Confirm build, environment, data, preconditions, expected result, and observed result.
- Keep passed, failed, blocked, skipped, and not-tested outcomes distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
