# API functional execution

## Use when

Use this variant when service endpoints are tested directly.

## Task guidance

For **Execute Functional Testing**, record request, auth context, headers, body, status, response schema, side effects, cleanup, and correlation identifiers.

## Decision checks

- Confirm build, environment, data, preconditions, expected result, and observed result.
- Keep passed, failed, blocked, skipped, and not-tested outcomes distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
