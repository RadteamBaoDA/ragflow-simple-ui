# UI functional execution

## Use when

Use this variant when browser interactions are tested.

## Task guidance

For **Execute Functional Testing**, record viewport, browser, theme, locale, roles, state, accessibility-relevant behavior, screenshots, and network conditions.

## Decision checks

- Confirm build, environment, data, preconditions, expected result, and observed result.
- Keep passed, failed, blocked, skipped, and not-tested outcomes distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
