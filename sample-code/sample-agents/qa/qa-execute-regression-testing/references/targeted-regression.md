# Targeted regression

## Use when

Use this variant when impact analysis identifies a bounded risk surface.

## Task guidance

For **Execute Regression Testing**, select changed behavior, direct consumers, dependencies, adjacent rules, historical defects, and high-risk journeys.

## Decision checks

- Confirm build, environment, data, preconditions, expected result, and observed result.
- Keep passed, failed, blocked, skipped, and not-tested outcomes distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
