# Smoke regression

## Use when

Use this variant when rapid confidence in deployment or build viability is needed.

## Task guidance

For **Execute Regression Testing**, run only critical startup, authentication, primary journey, key integration, and health checks; state excluded risk.

## Decision checks

- Confirm build, environment, data, preconditions, expected result, and observed result.
- Keep passed, failed, blocked, skipped, and not-tested outcomes distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
