# Visual defect

## Use when

Use this variant when layout, style, responsive, theme, or content presentation is wrong.

## Task guidance

For **Report and Triage Defect**, capture viewport, device, browser, theme, locale, screenshot, design reference, and usability impact.

## Decision checks

- Confirm build, environment, data, preconditions, expected result, and observed result.
- Keep passed, failed, blocked, skipped, and not-tested outcomes distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
