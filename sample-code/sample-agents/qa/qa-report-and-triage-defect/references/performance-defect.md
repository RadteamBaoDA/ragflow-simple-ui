# Performance defect

## Use when

Use this variant when latency, throughput, capacity, or resource behavior violates expectation.

## Task guidance

For **Report and Triage Defect**, capture workload, environment, measurement, baseline, actual distribution, resource signals, and user impact.

## Decision checks

- Confirm build, environment, data, preconditions, expected result, and observed result.
- Keep passed, failed, blocked, skipped, and not-tested outcomes distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
