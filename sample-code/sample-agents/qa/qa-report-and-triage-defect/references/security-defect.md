# Security defect

## Use when

Use this variant when a test reveals potential confidentiality, integrity, identity, access, or audit weakness.

## Task guidance

For **Report and Triage Defect**, minimize sensitive reproduction data, restrict evidence access, record exploit preconditions and impact, and notify Security.

## Decision checks

- Confirm build, environment, data, preconditions, expected result, and observed result.
- Keep passed, failed, blocked, skipped, and not-tested outcomes distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
