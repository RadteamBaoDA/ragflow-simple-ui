# Functional defect

## Use when

Use this variant when behavior violates a functional expectation.

## Task guidance

For **Report and Triage Defect**, capture requirement link, exact steps, data, expected and actual outcome, frequency, role, business impact, and evidence.

## Decision checks

- Confirm build, environment, data, preconditions, expected result, and observed result.
- Keep passed, failed, blocked, skipped, and not-tested outcomes distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
