# Hotfix test scope

## Use when

Use this variant when urgent corrective scope limits available test time.

## Task guidance

For **Analyze Test Scope**, prioritize reproduction, direct fix proof, highest-risk regression, rollback validation, and explicitly deferred coverage.

## Decision checks

- Confirm build, environment, data, preconditions, expected result, and observed result.
- Keep passed, failed, blocked, skipped, and not-tested outcomes distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
