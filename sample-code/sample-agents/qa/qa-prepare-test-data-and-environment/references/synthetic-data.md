# Synthetic test data

## Use when

Use this variant when real data is unnecessary or prohibited.

## Task guidance

For **Prepare Test Data and Environment**, generate representative valid, invalid, boundary, relational, volume, and role-scoped data without real identities.

## Decision checks

- Confirm build, environment, data, preconditions, expected result, and observed result.
- Keep passed, failed, blocked, skipped, and not-tested outcomes distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
