# Masked production-like data

## Use when

Use this variant when realistic shape is needed under privacy controls.

## Task guidance

For **Prepare Test Data and Environment**, verify masking irreversibility, referential integrity, access, retention, refresh, and prohibited sensitive fields.

## Decision checks

- Confirm build, environment, data, preconditions, expected result, and observed result.
- Keep passed, failed, blocked, skipped, and not-tested outcomes distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
