# Integration environment

## Use when

Use this variant when multiple services or external sandboxes must coordinate.

## Task guidance

For **Prepare Test Data and Environment**, baseline versions, endpoints, credentials, dependencies, data reset, observability, ownership, and outage handling.

## Decision checks

- Confirm build, environment, data, preconditions, expected result, and observed result.
- Keep passed, failed, blocked, skipped, and not-tested outcomes distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
