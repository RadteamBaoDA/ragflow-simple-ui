# Fixed-price delivery

## Use when

Use this variant when scope and acceptance are contractually bounded.

## Task guidance

For **Estimate Schedule and Budget**, emphasize baseline scope, milestone payments, acceptance windows, contingency ownership, and formal change control.

## Decision checks

- Confirm owners, dates, dependencies, confidence, and approval state.
- Do not treat coordination evidence as a specialist delivery gate.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
