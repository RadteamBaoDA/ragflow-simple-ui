# Plan Resources

## Purpose

Produce a role-based staffing and capacity plan.

## Task responsibility

Own delivery governance, coordination, customer alignment, and project controls. Do not invent contractual commitments, technical approvals, test evidence, or customer acceptance.

## Core method

1. Resolve **Demand by Phase** using task evidence, applicable constraints, alternatives, and explicit acceptance criteria.
2. Resolve **Team Composition** using task evidence, applicable constraints, alternatives, and explicit acceptance criteria.
3. Build **Allocation Plan** from dependencies, capacity, uncertainty, constraints, and reviewable assumptions.
4. Identify and rank **Skill Gaps** by evidence, impact, likelihood, and affected owner.
5. Resolve **Onboarding and Ramp-up** using task evidence, applicable constraints, alternatives, and explicit acceptance criteria.
6. Resolve **Backup and Continuity** using task evidence, applicable constraints, alternatives, and explicit acceptance criteria.
7. Reconcile contradictions and state unresolved evidence, decision, and ownership gaps.

## Quality checks

- Tie commitments to accountable owners, dates, dependencies, estimates, and approval evidence.
- Keep coordination status distinct from specialist quality, security, and production gates.
- Confirm proposed changes are separated from approved baseline content.
- Confirm acceptance, approval, test, release, and customer decisions are claimed only with evidence.
