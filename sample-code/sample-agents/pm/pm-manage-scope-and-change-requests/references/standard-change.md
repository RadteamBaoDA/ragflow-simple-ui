# Standard change request

## Use when

Use this variant when a non-emergency request changes an approved baseline.

## Task guidance

For **Manage Scope and Change Requests**, emphasize business, technical, schedule, cost, quality, contract, and acceptance impacts before approval.

## Decision checks

- Confirm owners, dates, dependencies, confidence, and approval state.
- Do not treat coordination evidence as a specialist delivery gate.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
