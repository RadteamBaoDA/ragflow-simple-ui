# Scope clarification

## Use when

Use this variant when the request may already be covered by the approved baseline.

## Task guidance

For **Manage Scope and Change Requests**, emphasize quote the baseline, map the request, document interpretation, and obtain recorded confirmation.

## Decision checks

- Confirm owners, dates, dependencies, confidence, and approval state.
- Do not treat coordination evidence as a specialist delivery gate.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
