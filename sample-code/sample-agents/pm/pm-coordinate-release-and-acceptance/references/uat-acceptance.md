# UAT acceptance

## Use when

Use this variant when customer representatives validate agreed business outcomes.

## Task guidance

For **Coordinate Release and Acceptance**, emphasize entry criteria, scenario coverage, defect disposition, deviations, sign-off authority, and acceptance record.

## Decision checks

- Confirm owners, dates, dependencies, confidence, and approval state.
- Do not treat coordination evidence as a specialist delivery gate.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
