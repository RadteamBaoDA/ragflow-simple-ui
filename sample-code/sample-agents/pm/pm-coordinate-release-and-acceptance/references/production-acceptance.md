# Production acceptance

## Use when

Use this variant when the customer accepts a deployed deliverable.

## Task guidance

For **Coordinate Release and Acceptance**, emphasize release identity, production evidence, outstanding obligations, warranty window, support contacts, and formal sign-off.

## Decision checks

- Confirm owners, dates, dependencies, confidence, and approval state.
- Do not treat coordination evidence as a specialist delivery gate.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
