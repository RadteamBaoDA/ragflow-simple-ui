# Internal release

## Use when

Use this variant when the deliverable moves to an internal integration or QA environment.

## Task guidance

For **Coordinate Release and Acceptance**, emphasize build identity, included scope, environment readiness, smoke evidence, known limitations, and owner handoff.

## Decision checks

- Confirm owners, dates, dependencies, confidence, and approval state.
- Do not treat coordination evidence as a specialist delivery gate.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
