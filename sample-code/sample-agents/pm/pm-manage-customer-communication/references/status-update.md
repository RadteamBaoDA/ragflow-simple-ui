# Routine status update

## Use when

Use this variant when the audience needs a concise periodic delivery view.

## Task guidance

For **Manage Customer Communication**, emphasize plan versus actual, milestone health, recent outcomes, next actions, decisions, and RAID changes.

## Decision checks

- Confirm owners, dates, dependencies, confidence, and approval state.
- Do not treat coordination evidence as a specialist delivery gate.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
