# Escalation

## Use when

Use this variant when a threshold breach needs timely management action.

## Task guidance

For **Manage Customer Communication**, emphasize facts, impact, attempted responses, options, required decision, owner, and escalation deadline.

## Decision checks

- Confirm owners, dates, dependencies, confidence, and approval state.
- Do not treat coordination evidence as a specialist delivery gate.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
