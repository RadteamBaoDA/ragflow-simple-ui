# Manage Risks and Issues

## Purpose

Produce a prioritized RAID update with owned responses.

## Task responsibility

Own delivery governance, coordination, customer alignment, and project controls. Do not invent contractual commitments, technical approvals, test evidence, or customer acceptance.

## Core method

1. Analyze **Risks** by trigger, exposure, consequence, control, and residual state.
2. Resolve **Issues** using task evidence, applicable constraints, alternatives, and explicit acceptance criteria.
3. Resolve **Assumptions** using task evidence, applicable constraints, alternatives, and explicit acceptance criteria.
4. Resolve **Dependencies** using task evidence, applicable constraints, alternatives, and explicit acceptance criteria.
5. Resolve **Response Actions** using task evidence, applicable constraints, alternatives, and explicit acceptance criteria.
6. Resolve **Escalations** using task evidence, applicable constraints, alternatives, and explicit acceptance criteria.
7. Reconcile contradictions and state unresolved evidence, decision, and ownership gaps.

## Quality checks

- Tie commitments to accountable owners, dates, dependencies, estimates, and approval evidence.
- Keep coordination status distinct from specialist quality, security, and production gates.
- Confirm proposed changes are separated from approved baseline content.
- Confirm acceptance, approval, test, release, and customer decisions are claimed only with evidence.
