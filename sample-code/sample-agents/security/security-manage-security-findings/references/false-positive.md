# False-positive disposition

## Use when

Use this variant when evidence indicates the reported weakness is not present or reachable.

## Task guidance

For **Manage Security Findings**, document tool claim, code or runtime evidence, assumptions, reviewer, suppression scope, expiry, and revalidation trigger.

## Decision checks

- Confirm asset, boundary, attack precondition, evidence, control, and residual risk owner.
- Stop active testing when authorization or rules of engagement are incomplete.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
