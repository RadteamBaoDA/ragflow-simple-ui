# Cloud threat model

## Use when

Use this variant when managed cloud infrastructure and identities are in scope.

## Task guidance

For **Create Threat Model**, analyze IAM, network exposure, metadata access, storage policy, control plane, secrets, logging, region, and supply chain.

## Decision checks

- Confirm asset, boundary, attack precondition, evidence, control, and residual risk owner.
- Stop active testing when authorization or rules of engagement are incomplete.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
