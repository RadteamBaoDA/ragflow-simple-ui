# Exception security gate

## Use when

Use this variant when a release requests a documented deviation.

## Task guidance

For **Issue Security Release Gate**, state unmet control, business need, exposure, compensating controls, expiry, risk owner, monitoring, and required remediation.

## Decision checks

- Confirm asset, boundary, attack precondition, evidence, control, and residual risk owner.
- Stop active testing when authorization or rules of engagement are incomplete.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
