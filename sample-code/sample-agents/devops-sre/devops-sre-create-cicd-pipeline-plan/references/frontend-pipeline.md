# Frontend pipeline

## Use when

Use this variant when browser assets or frontend applications are built and promoted.

## Task guidance

For **Create CI/CD Pipeline Plan**, define install lock, lint, typecheck, unit and UI tests, build, security scan, artifact integrity, environment config, and deployment.

## Decision checks

- Confirm target, version, authorization, telemetry, blast radius, and recovery path.
- Keep planned, attempted, completed, failed, and rolled-back states distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
