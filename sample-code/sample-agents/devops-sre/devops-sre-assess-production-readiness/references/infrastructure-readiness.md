# Infrastructure readiness

## Use when

Use this variant when platform capacity or controls must support production.

## Task guidance

For **Assess Production Readiness**, evaluate provisioning, security, network, capacity, resilience, backup and restore, drift, observability, and support ownership.

## Decision checks

- Confirm target, version, authorization, telemetry, blast radius, and recovery path.
- Keep planned, attempted, completed, failed, and rolled-back states distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
