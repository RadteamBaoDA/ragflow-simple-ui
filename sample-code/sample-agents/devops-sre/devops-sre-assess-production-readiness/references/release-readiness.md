# Release readiness

## Use when

Use this variant when a specific release package is entering production.

## Task guidance

For **Assess Production Readiness**, evaluate artifact identity, gates, environment, migrations, deployment, rollback, monitoring, support, communication, and exceptions.

## Decision checks

- Confirm target, version, authorization, telemetry, blast radius, and recovery path.
- Keep planned, attempted, completed, failed, and rolled-back states distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
