# Service readiness

## Use when

Use this variant when one service is entering or changing production operation.

## Task guidance

For **Assess Production Readiness**, evaluate ownership, SLOs, capacity, dependencies, configuration, telemetry, runbooks, on-call, failure recovery, and load evidence.

## Decision checks

- Confirm target, version, authorization, telemetry, blast radius, and recovery path.
- Keep planned, attempted, completed, failed, and rolled-back states distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
