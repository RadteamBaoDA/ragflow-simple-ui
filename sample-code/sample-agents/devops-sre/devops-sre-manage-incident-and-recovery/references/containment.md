# Incident containment

## Use when

Use this variant when active impact or threat must be limited.

## Task guidance

For **Manage Incident and Recovery**, define authorized reversible actions, blast-radius reduction, evidence preservation, customer impact, monitoring, and handoff to recovery.

## Decision checks

- Confirm target, version, authorization, telemetry, blast radius, and recovery path.
- Keep planned, attempted, completed, failed, and rolled-back states distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
