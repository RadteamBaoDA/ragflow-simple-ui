# Post-incident review

## Use when

Use this variant when the incident is stable enough for learning.

## Task guidance

For **Manage Incident and Recovery**, build evidence-based timeline, contributing factors, control gaps, detection and response analysis, corrective actions, owners, and deadlines without blame.

## Decision checks

- Confirm target, version, authorization, telemetry, blast radius, and recovery path.
- Keep planned, attempted, completed, failed, and rolled-back states distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
