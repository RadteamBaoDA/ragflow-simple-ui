# Incident triage

## Use when

Use this variant when an alert or report must be assessed quickly.

## Task guidance

For **Manage Incident and Recovery**, confirm impact, scope, severity, ownership, timeline, signals, immediate safety, communication cadence, and next diagnostic action.

## Decision checks

- Confirm target, version, authorization, telemetry, blast radius, and recovery path.
- Keep planned, attempted, completed, failed, and rolled-back states distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
