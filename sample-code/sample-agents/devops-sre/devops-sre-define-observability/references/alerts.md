# Alert design

## Use when

Use this variant when operators need actionable notification of symptoms.

## Task guidance

For **Define Observability**, define symptom, threshold or burn rate, duration, routing, severity, runbook, deduplication, maintenance behavior, and test.

## Decision checks

- Confirm target, version, authorization, telemetry, blast radius, and recovery path.
- Keep planned, attempted, completed, failed, and rolled-back states distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
