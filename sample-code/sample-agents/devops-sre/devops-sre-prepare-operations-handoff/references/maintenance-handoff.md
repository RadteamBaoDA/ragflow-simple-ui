# Maintenance handoff

## Use when

Use this variant when scheduled operational work transfers to another team.

## Task guidance

For **Prepare Operations Handoff**, include schedule, scope, dependencies, access, backup, steps, validation, rollback, communication, and approval.

## Decision checks

- Confirm target, version, authorization, telemetry, blast radius, and recovery path.
- Keep planned, attempted, completed, failed, and rolled-back states distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
