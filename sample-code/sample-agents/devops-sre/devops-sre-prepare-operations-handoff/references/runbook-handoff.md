# Runbook handoff

## Use when

Use this variant when operators need executable procedures.

## Task guidance

For **Prepare Operations Handoff**, include trigger, prerequisites, safe steps, expected signals, stop conditions, rollback, escalation, evidence capture, owner, and last validation.

## Decision checks

- Confirm target, version, authorization, telemetry, blast radius, and recovery path.
- Keep planned, attempted, completed, failed, and rolled-back states distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
