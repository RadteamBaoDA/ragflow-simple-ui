# On-call handoff

## Use when

Use this variant when support ownership and escalation transfer.

## Task guidance

For **Prepare Operations Handoff**, include service scope, SLOs, alerts, dashboards, runbooks, known issues, escalation tree, access, communication, and readiness confirmation.

## Decision checks

- Confirm target, version, authorization, telemetry, blast radius, and recovery path.
- Keep planned, attempted, completed, failed, and rolled-back states distinct.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
