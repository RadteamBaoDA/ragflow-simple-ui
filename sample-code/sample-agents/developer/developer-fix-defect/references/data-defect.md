# Data defect

## Use when

Use this variant when incorrect stored, transformed, or migrated data causes the issue.

## Task guidance

For **Fix Defect**, protect evidence, identify affected records and lineage, define repair and validation, and avoid irreversible cleanup without approval.

## Decision checks

- Confirm entrypoints, contracts, error paths, side effects, tests, and compatibility.
- Record exact evidence for implemented behavior and explicit gaps for unverified behavior.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
