# Operations handoff

## Use when

Use this variant when deployment or production support is the next consumer.

## Task guidance

For **Prepare Technical Handoff**, include configuration, secrets boundary, migrations, dependencies, observability, rollout, rollback, runbook changes, and ownership.

## Decision checks

- Confirm entrypoints, contracts, error paths, side effects, tests, and compatibility.
- Record exact evidence for implemented behavior and explicit gaps for unverified behavior.
- If multiple references apply, reconcile their constraints explicitly instead of merging incompatible advice.
